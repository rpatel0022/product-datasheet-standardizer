Pipeline Steps

1

Load & Merge

Load 21 CSV files with different schemas, detect schema differences, and merge into a unified DataFrame.

2

Standardize Columns

Normalize column names (lowercase, underscores), resolve synonyms (e.g., "goods_title_link" → "product_name"), extract categories from filenames.

3

Clean Data Types

Strip currency symbols from prices, convert to float. Coalesce full and short product names. Standardize text fields.

4

Drop Junk Columns

Columns with >70% null data only existed in a few source files. Drop them to keep the unified dataset clean (7 columns removed).

5

Handle Missing Values

Median fill for price, "Unknown" for categorical fields (discount, selling_proposition). Only 4 columns need treatment after dropping junk.

6

Fuzzy Deduplication

Uses rapidfuzz token sort ratio (threshold: 85) to detect near-duplicate product names. Removes exact duplicates first, then identifies fuzzy groups.
